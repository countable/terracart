# Ghost and shrine spirit artwork

Native artwork by **jfranci_px**, from the Dark Fantasy Monsters asset pack.
`1Fullsheet_Ghost.png` is shared by hostile ghosts and friendly shrine spirits;
the latter use the separate `shrine_spirit` texture and gameplay identity.
The original pixels and palette are preserved.

The source pack is archived at
`~/.artifacts/terracart-art/unused_art/DarkFantasyMonsters/`.
